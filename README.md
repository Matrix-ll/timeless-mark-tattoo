# Timeless Mark Tattoo

A custom tattoo studio in Monterey Park, California. Bespoke, permanent art.

## Pages
- `/` — Homepage with hero, manifesto, gallery preview, and contact
- `/gallery` — 40-piece portfolio with pricing and Stripe payment links
- `/about` — Studio story and artist information
- `/faq` — Frequently asked questions
- `/contact` — Contact form and studio location

## Tech stack
Vite · React · TypeScript · Tailwind CSS

## Local development
```sh
npm install
npm run dev
```
